# Application audit — updated 2026-10-13 (Vancouver)

## Verdict

The original comprehensive analyzer is preserved and the integrated development preview works. It is **not yet a validated system for copying profitable traders**. The branch was deployed to both existing Fly apps on October 13, 2026. This audit found material errors in accounting interpretation, financial-input selection, authentication, dependencies and error handling; the repairs below are implemented and tested locally. Passing software tests does not establish investment performance.

## What the saved portfolio actually says

A consistent production SQLite backup taken on October 10 contains 3,714 company analyses, 568 paper positions and 578,974 filing rows. Its integrity check passed. These counts do not prove freshness, distinct economic events or accuracy.

The user's approximately $15,600 observation may reflect a different refresh. The reproducible backup shows $15,461.82. It is not a verified CAGR, total-account return, or comparison against SPY. All 140 open positions have analysis timestamps older than two days at the audit; an analysis timestamp is not a quote timestamp. The saved analysis dates span May 15–October 9.

The legacy ledger computes price ratios without reconciling share counts after splits. SVRN shows +5,312.54% while its holding period spans a **1-for-20 reverse split effective March 30**. HCAI shows +5,020.52% while its exit date coincides with a **1-for-30 reverse split effective April 13**. Primary evidence: [SVRN SEC release](https://www.sec.gov/Archives/edgar/data/1869467/000091957426001900/d12128691_ex99-1.htm), [HCAI SEC release](https://www.sec.gov/Archives/edgar/data/1958399/000121390026041513/ea028499601ex99-1.htm), [Nasdaq HCAI notice](https://www.nasdaqtrader.com/TraderNews.aspx?id=ECA2026-237). Those changes multiply the price per remaining share; they do not create proportional wealth. Historical rows have been preserved, not silently rewritten with incomplete adjustments.

The old chart aggregates whichever position snapshots exist each day and does not carry forward closed-trade cash. Its fixed-initial-dollar SPY overlay was not comparable. That overlay is removed, and the chart now describes recorded position values and changing coverage.

## Implemented repairs

- Preserved original rankings, company analysis, filings, charts, forensic models, leaderboard and paper portfolio. Public-trade evidence expands within the original dashboard and in company detail. The screener hides known excluded instruments by default; its research-only inclusion checkbox restores them for search and inspection.
- Fixed missing FCF receiving maximum frontend points; zero and non-finite values have explicit handling. Removed silent clipping of FCF yield at 100%; legacy saved values require reanalysis.
- Annual SEC selection now rejects quarterly durations carried inside annual filings, chooses a common annual period across concepts, retains filing provenance and respects optional as-of cutoffs. Prior years cannot silently skip a missing year. Yahoo statement reads also align reporting periods instead of dropping nulls and shifting years. [SEC API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) describes the annual duration window used.
- Dividend yield is annual cash dividend per share divided by price. Debt/equity is derived from amounts, with non-positive equity unavailable. Missing capex does not become zero. Long-term debt alone no longer becomes total debt. Missing debt/cash disables dependent net-debt, EPV and ROIC calculations; explicit zero remains valid. Debt reconstruction requires the mapped components.
- Invalidated old financial/market cache generations. Added retrieval timestamps, annual-period labels and a company input-date/provenance disclosure. Retrieval time is explicitly different from a verified exchange quote timestamp.
- Applied the formerly ignored minimum-holding-days filter to factor diagnostics. Removed claims that in-sample OLS coefficients are optimal trading weights. Saved old runs retain their dates; a fresh local run processed exactly 568 positions.
- Replaced password-valued cookies with signed, expiring sessions. Browser API calls use an authenticated same-origin server proxy; backend credentials stay server-side. Added login throttling, body limits, origin checks, fail-closed Fly configuration, header-only backend keys and explicit CORS origins. Removed the hardcoded market-provider fallback key. Rotation of previously exposed production credentials remains necessary.
- Fixed the browser-discovered diagnostic crash: localhost origin normalization caused a 403, then the UI treated its error body as a successful result. Added the missing response checks, corrected origin handling and added a built-app regression test. Price/snapshot failures now report errors instead of success with undefined counts.
- Updated Next.js to 16.4.0 and compatible dependency fixes; updated FastAPI, Starlette, Requests, Yahoo Finance and curl-cffi together. Removed the unused shadcn scaffolding dependency while preserving generated components. Runtime dependency scans report no known vulnerabilities as of the audit. Five high dependency findings remain in the ESLint development chain, rooted in an unpatched braces advisory: [GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm). A clean runtime scan is not a security certification.
- Wrapped portfolio/leaderboard navigation for narrow screens and labeled leaderboard values as saved analyses, which can differ from the dashboard's recalculated scores.
- Added the Portfolio **Reconciliation & ledger** tab. The read-only historical report reviews all 568 positions, identifies two confirmed split overlaps and explicitly reports zero fully reconciled positions. Split-only scenarios are conditional on unadjusted stored prices; they are not corrected returns.
- Added an independent append-only paper ledger for funding, withdrawals, buys, sells, marks, fees, splits and dividends. Decimal accounting retains sale proceeds as cash. Transactions reject overspending/shorting, invalid numbers, future or out-of-order events, and adjusted or stale execution quotes. Repeated event IDs are idempotent only for identical payloads. Dividend cash requires documented entitlement. Manual source assertions remain unverified; there is no broker connection or benchmark-return claim.
- Disabled legacy automatic opening/closing by default. Explicit opt-in `ENABLE_LEGACY_PAPER_ALLOCATION=1` limits new allocations to BUY/STRONG_BUY and known instrument exclusions; it does not make the old strategy validated. Historical HOLD entries remain intact.
- Replaced the ambiguous DCF formulation in both analysis paths with a disclosed equity scenario: OCF minus capex under zero future net borrowing, discounted at assumed cost of equity without subtracting debt a second time. Comparable growth history and current shares/price/market-cap reconciliation are required. Nine growth/discount sensitivities and bounded reverse-growth solving are displayed. This is a conditional model, not measured FCFE or a verified forecast. The basis follows [cash-flow/discount-rate matching](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/lectures/val.html).
- Added common-instrument/sector screening and suppressed generic valuation outputs for known exclusions. Leaderboard and individual percentiles use one filtered universe and consistent tie ranks. The restored snapshot has 2,593 potentially eligible rows and 1,121 excluded by security, sector or size filters; remaining identity is provisional. Saved scores retain their original model vintage.
- Resolved all repository ESLint errors/warnings and guarded leaderboard loads against stale responses when switching metrics; failed loads now surface an error.

## What must happen before investment claims or release

1. **Complete historical reconciliation:** the new ledger is implemented, but it does not repair old prices or reconstruct missing historical cash. Acquire unadjusted entry/exit history, complete corporate actions/dividends/delistings, fill times and costs. Audit every extreme result; then produce cash-flow-aware returns and a matching benchmark.
2. **Validate the scenarios:** the mixed DCF contract is replaced, with analytic reference tests and current-share guards. Actual debt issuance/repayments, calibrated assumptions, sector models and broader issuer reference comparisons remain missing. Do not treat fair value or the 1–99 score as a validated forecast. Saved batch scores and detail views have different vintages and need versioned rebuilding.
3. **Finish canonical instrument identity:** known debt/preferred-like instruments and specialized sectors are excluded from general rankings. Title/type screening does not prove the remaining records are the correct common equity. Generic issuer names or ticker-only aliases can still pass the screen, and old clipped 100% FCF yields remain in saved rankings until reanalysis. Establish authoritative security IDs, corporate-action continuity and sector-appropriate models.
4. **Connect entitled sources:** Quiver for congressional/corporate-insider records; SEC ownership XML for primary evidence; Nansen for wallet history/PnL and observed swaps. The existing adapters fetch bounded recent samples only, and credentials are not configured. [Quiver entitlements](https://api.quiverquant.com/pricing/) and [Nansen wallet PnL documentation](https://docs.nansen.ai/api/profiler/address-pnl-and-trade-performance) are the relevant account checks. No purchase was made.
5. **Build complete histories and test a copying policy:** actor identities, disclosure delays, amendments, transfers/cost basis, liquidity, gas/spread/slippage, failures and losing actors. Separate an actor's observed profit from what a follower could earn after disclosure. Freeze actor selection before an untouched later evaluation period and compare net returns, drawdown and uncertainty against suitable benchmarks. More data alone does not establish an edge.
6. **Release safely:** the local restore/migration drill passed. Image builds, the authorized production rollout, API/session key rotation and live login/proxy checks are complete. A fresh consistent database backup and Fly recovery snapshot were prepared. Separate staging and live paid-provider verification remain outstanding. Preserve the recovery images and do not publish investment-performance claims before the accounting/source work is complete. Track the unpatched development-tool advisory. No Cloudflare deployment configuration was found in this repository.

There is no verified profitable-trader leaderboard, complete copying backtest, or broker execution in this branch. Quiver, Nansen and Polygon/Massive keys are absent from the inspected backend secret names; no secret values were displayed.

## October 13 production release

Both `stockanalyzer-api` and `stockanalyzer-web` run the reviewed release images. The fresh pre-release database has 138 open and 430 closed positions (568 total); CIX and THO had closed on October 12 before this deployment. The October 10 snapshot above remains a historical audit baseline. Every original analysis, position and filing row matched its pre-release hash after rollout. The independent ledger has zero events and legacy automatic allocation is disabled.

Authenticated live checks covered the original routes, signed-cookie login, direct/API protection, same-origin rejection, consistent rankings, split reconciliation and rejected invalid paper writes without creating test entries. Apple live data returned the new valuation scenario and nine sensitivities. Quiver/Nansen remain unconnected.

A live check exposed a SEC refresh failure. The filings endpoint now returns existing stored metadata with its original saved date and a visible notice that newer filings may be missing. Failed refreshes never advance that date. Two regression tests cover preserved cached filings and explicit failure when no saved data exists.
