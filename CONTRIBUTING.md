# Contributing

This is an early community project. Contributors and co-maintainers are welcome.
The founder has limited maintenance time; contributions do not come with a
guaranteed review deadline. See [the roadmap](ROADMAP.md) for focused work.

1. Run the local setup and checks in the README before editing.
2. For substantial changes, open an issue with the problem, proposed approach
   and a small, testable acceptance criterion. Small fixes can go directly to a PR.
3. Use a branch and keep each PR focused. Explain what changed, how you checked
   it, and what remains unverified. Add a regression test for behavior fixes.
4. Use synthetic data. Never upload production databases, personal records,
   credentials, real payment details or private screenshots.
5. Do not connect the original founder's services, deploy automatically, or make
   paid API calls as part of tests. Use your own entitled data sources for live work.

By submitting a contribution, you confirm that you may share it under the
repository's MIT license. Keep third-party copyright and license notices.
External datasets, models and services keep their own terms.

## Becoming a co-maintainer

Start with a small reviewed PR. If you want to help maintain a component, open
an issue describing your area, availability and proposed first milestone.
Repository or deployment access requires separate owner approval.
